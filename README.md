# .github

Default community-health files for [@granolacowboy](https://github.com/granolacowboy)'s
repositories: `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, and `SECURITY.md` apply across any repo
that doesn't define its own.

[PUBLIC_DEVELOPMENT.md](PUBLIC_DEVELOPMENT.md) defines the shared public-history policy. The
reusable workflow under `.github/workflows/` enforces the narrow boundary against agent
attribution and session-provenance boilerplate.

Looking for the profile? See **[github.com/granolacowboy](https://github.com/granolacowboy)**.

# Contributing

These repositories are **reference implementations** and field tools for applied AI in regulated (primarily legal) work. Contributions that sharpen correctness, security, determinism, or clarity are welcome.

- Open an issue before a large change so we can agree on scope.
- Keep changes focused; include tests/evals where a repo has them.
- Never include client, matter, or personal data in code, tests, fixtures, or issues.
- Security issues: follow [SECURITY.md](SECURITY.md), not a public issue.
- Public commits and pull requests follow [PUBLIC_DEVELOPMENT.md](PUBLIC_DEVELOPMENT.md): preserve engineering rationale, but keep agent/session provenance out of the public history.
